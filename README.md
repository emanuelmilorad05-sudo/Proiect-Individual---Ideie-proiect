# Proiect-Individual---aplicatie-tip-maps
O aplicatie care recomanda cea mai buna ruta de luat, folosind mijloacele de transport, si durata de asteptat. (exemplu: iei autobuzul m22 din ciarda rosie, pana la statia aem, ca sa iei din aem tranvaiul 4 care vine in 4 minute dupa coborarea din autobuz, aplicatia aproximeaza timpul pentru schimbarea mijloacelor de transport.)
